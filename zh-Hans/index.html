I体验

不是屏幕上的棋盘。
而是棋桌前的一席之地。

Scacelith 重现了真实对局的种种要素：大厅、寂静、棋钟、注视着你的对手，以及锦标赛的仪式感。

♔

第一人称视角

你透过自己机器人的双眼观看一切。环顾大厅，俯身靠近棋盘，抬头看向对手，或瞥一眼身旁的对局记录表。

♖

比赛规则

摸子即须走子。你的手按下棋钟，这步棋才算完成。一旦走出违例着法，裁判就会出面；第二次违例即判负。

♗

亲笔记录

双方棋手都在各自的记录表上记下每一步棋，各有各的笔迹，每满四十回合翻一页。你能听见笔尖在纸上沙沙作响。

♕

旗鼓相当的对手

与你水平相当的 Stockfish 19，从新手（800）到满级（3500），每局结束后都按 FIDE 规则计算等级分。

♘

为本作量身打造

从零编写的引擎：基于物理的光照，大理石、打蜡的木材、瓷与黄铜，透窗而入的阳光，柔和的阴影与反射。

♙

十种语言

英语、法语、德语、西班牙语、乌克兰语、俄语、阿拉伯语、日语，以及简体和繁体中文。阿拉伯语采用从右到左的排版。

II游戏模式

每一局棋，
自有一方棋桌。

所有对局都在同一座大厅中进行，从标题画面即可开始。即使离线，Stockfish 也随时准备与你对弈。

  1. 新对局

    以你选择的棋力挑战 Stockfish，用时从子弹棋到慢棋任选；也可以在同一台电脑上与朋友对弈，双方各自以自己机器人的视角下棋。

  2. 教练

    一位老师坐在你对面，以你的水平与你对弈，并为你讲解棋局：威胁、好棋、失误。从国际象棋规则到专家水平，配有合成语音（英语发音，附中文字幕）。

  3. 在线对局

    通过 Scacelith 服务器与真人对手对弈：计分对局、匹配对手、挑战和私人对局。对手的机器人会实时同步其一举一动。

  4. 观看对局

    两个 Stockfish 相互对弈，而你隐身其间，在大厅中自由穿行，从一个视角切换到另一个视角。

  5. 已保存的对局

    你的对局会保存为 PGN 文件。可以在大厅中重播，还原真实的思考时间和棋钟；也可以导入其他程序中的对局。

V在线

真实的对手，
同一座大厅。

在游戏中登录官方服务器，与来自世界各地的棋手对弈，依然是第一人称视角。

  • 所有官方用时均可进行计分对局，每种用时各有一个 FIDE 等级分。
  • 匹配对手、按用户名发起挑战、凭代码进行私人对局，以及两台电脑之间的直连对局。
  • 公平对弈：自动检查、由引擎分析已结束的对局，以及棋手举报。
  • 在本网站查看你的对局记录：每局都可下载为 PGN 或 GIF 动图。
  • 任何人都可以运行社区服务器：服务器及其 API 都是自由软件。

VII制作人员

制作人员与致谢

国际象棋引擎
Stockfish 19，由 Stockfish 开发者制作（GNU GPL v3）。其神经网络使用 Leela Chess Zero 项目提供的数据训练（开放数据库许可协议）。
教练语音
教练模式的合成语音由 Supertonic 3 生成。Supertonic 3 是 Supertone 公司的模型，依据 OpenRAIL-M 许可证使用。
字体
Georg Duffner 设计的 EB Garamond、Natanael Gama 设计的 Cinzel 和 Khaled Hosny 设计的 Amiri，均采用 SIL Open Font License；棋子符号来自 GNU FreeFont。
开局
开局名称来自 lichess.org 的 chess-openings 数据库，已贡献至公有领域（CC0）。
