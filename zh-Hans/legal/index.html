隐私

Scacelith 不展示任何广告，不出售任何数据，也不统计访问量。个人数据仅用于运行本网站和官方服务器，详见下文。数据控制者为发布者，可通过上方的联系邮箱与其联系。

在本网站上

  • 本网站由 GitHub 托管；与所有网站托管服务商一样，GitHub 会出于安全目的记录访问者的 IP 地址。 GitHub 隐私声明
  • 为显示最新发行版，你的浏览器会向 GitHub 的 API（api.github.com）发出请求；为显示服务器状态、排行榜、棋手和你的账号，它会向官方服务器（caissa.scacelith.com）发出请求。与任何请求一样，两者都会收到你的 IP 地址。
  • 本网站不设置 Cookie，也不做访问统计。它只在你的浏览器中保存你选择的语言，以及你登录后的会话：仅限当前标签页，或者在你勾选“在此设备上保持登录”时保存在此设备上。使用 Google 登录时，还会在当前标签页中保存一次性代码，直到它们被使用。这些都是网站正常运行所必需的，且只有官方服务器会收到会话和这些代码。
  • 预告片是一段 YouTube 视频。在你按下“同意并播放”之前，不会从 YouTube 加载任何内容；按下后，YouTube（Google）会收到你的 IP 地址，并可能在你的设备上存储 Cookie 或其他跟踪器。你的选择不会被记住：下次访问时会再次询问。 Google 隐私权政策
  • 在你按下“账号”页面上的“使用 Google 账号登录”之前，不会从 Google 加载任何内容。按下后，你的浏览器会前往 Google 的登录页面（accounts.google.com），随后 Google 会带着一个一次性代码把浏览器送回本网站，本网站再把该代码交给官方服务器。Google 会按照其自己的政策，收到你的 IP 地址以及你在其页面上输入的内容。 Google 隐私权政策

在游戏中

游戏会在你的电脑上保存其设置、你的本地战绩和你的登录状态。登录状态保存在系统的安全存储中：Windows 上为 DPAPI，macOS 上为钥匙串，Linux 上为 Secret Service 密钥环；如果都不可用，则保存在一个只有你的系统用户才能读取的文件中。

游戏不会自行发送任何数据：没有遥测，也不检查更新。只有在你打开“在线对局”页面时，它才会连接官方服务器；只有在你下载教练语音时，它才会连接 Hugging Face；进行直连对局时，它会连接对手的电脑，对手因此会得知你的 IP 地址（游戏还可能通过 UPnP 在你的路由器上打开端口）。

你在官方服务器上的账号

在游戏中或本网站上创建账号以及在线对弈时，以下数据会发送到由 OVH 在法国托管的官方服务器：

  • 账号：用户名、电子邮箱地址、密码（仅以 Argon2id 哈希值的形式存储）、双重验证密钥（已加密）和恢复码（已哈希处理）、注册日期和上次登录日期。
  • 使用 Google 登录：Google 会发送你的 Google 账号标识符、电子邮箱地址和姓名。服务器保存标识符和邮箱地址，姓名仅用于为你推荐用户名。
  • 已登录的设备：每次登录对应的设备名称（游戏的版本和系统，例如“Scacelith/1.0.0 win64”；在本网站上则为浏览器和系统）、IP 地址和使用日期。
  • 对局和等级分：每一局在线对局（棋手、着法、每步用时、结果、日期）以及你的等级分。对局过程中，你的头部和手部动作会实时转发给对手，且从不存储。
  • 安全日志：登录、失败的尝试和账号变更，以及相应的 IP 地址。
  • 公平对弈：你提交的或针对你的举报及其备注；放弃和错过的对局；处罚；以及对对局进行的检查，从伪造或不可能的着法到 Stockfish 引擎的统计数据。

处理目的和法律依据

  • 运行你的账号和在线对局（登录、匹配、等级分、对局记录、服务发送的电子邮件）：这是你注册使用的服务（《通用数据保护条例》(GDPR) 第 6 条第 1 款 (b) 项）。
  • 保护账号和服务器，确保对局公平（安全日志、IP 地址、公平对弈检查、处罚）：发布者和棋手的正当利益（GDPR 第 6 条第 1 款 (f) 项）。
  • 从 YouTube 播放预告片：你通过按钮表示的同意（GDPR 第 6 条第 1 款 (a) 项）。

所有人都能看到的内容

你的用户名、注册日期、等级分以及包含每一步着法的完整对局列表都是公开的，可在本网站上、通过服务器的 API 以及在每局对局的 PGN 中查看。你的电子邮箱地址、设备、登录记录、处罚和公平对弈检查记录从不显示。你可以拒绝直接挑战，但无法隐藏对局。

自动化决策

某些违反游戏通信协议的行为，例如伪造的消息或在当前局面下不可能走出的着法，是确凿的作弊证据：此时服务器会判相关账号本局告负，将其封禁 24 小时并从排行榜中移除，同时把其对手在过去 60 天内输给它的等级分退还给对手。24 小时内放弃、中止或错过三局对局，将暂停计分匹配 15 分钟，此后暂停时间会更长。仅凭引擎统计数据绝不会导致处罚：须由人来决定。你可以通过联系邮箱要求复核任何决定。

谁会收到你的数据

  • OVH SAS 在法国托管服务器及其数据。
  • Scaleway SAS（8 rue de la Ville-l'Évêque, 75008 Paris, France）负责发送服务器的电子邮件：它会收到你的邮箱地址、用户名和邮件内容。
  • 当你选择使用 Google 登录时，Google 会收到你的浏览器发送给它的内容，并受其自身的隐私权政策约束。
  • 服务器的管理员和审核员会查看账号数据和公平对弈数据，以运营本服务。
  • 其他棋手可以看到公开的内容；对局中，你的对手会看到你的着法和动作。
  • 除此之外没有其他人：任何数据都不会被出售、出租或用于广告。

账号数据保留在法国。GitHub、Google 和 Porkbun（负责转发发送到联系邮箱的邮件）位于美国：它们收到的数据受其自身政策以及它们为向欧盟以外传输数据所采取的保障措施约束。

保存期限

  • 账号：保存至你将其删除为止。邮箱地址始终未经确认的注册会在 24 小时后删除。
  • 已登录的设备：保存至你退出登录为止；闲置 30 天后删除；最长保存 90 天。
  • IP 地址：30 天后删除。服务器日志只保留截短的地址。
  • 安全日志：90 天。
  • 放弃和错过的对局：30 天。
  • 对局和等级分：服务器保留对局记录多久，就保存多久；这些记录同时也是你对手的记录。你的账号删除后，其中你的名字会替换为“deleted#”加一个编号。
  • 处罚、举报和公平对弈检查结果：予以保留，以免被封禁的棋手轻易卷土重来，并持续保护其他棋手。你的账号删除后，这些数据只与该账号的编号关联。
  • 备份：已删除的数据可能会在服务器的备份副本中短暂留存，直到该副本被替换。
  • 发送到联系邮箱的邮件：保存至答复所需的期限为止。
