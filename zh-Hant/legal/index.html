隱私權

Scacelith 不顯示任何廣告、不販售任何資料，也不做流量統計。個人資料僅用於運作本網站與官方伺服器，詳見下文。資料控管者為發布者，可透過上方的聯絡信箱與其聯繫。

在本網站上

  • 本網站由 GitHub 代管；如同所有網站代管業者，GitHub 會基於安全目的記錄訪客的 IP 位址。 GitHub 隱私權聲明
  • 為了顯示最新版本，你的瀏覽器會向 GitHub 的 API（api.github.com）發出要求；為了顯示伺服器狀態、排行榜、棋手與你的帳號，則會向官方伺服器（caissa.scacelith.com）發出要求。如同任何要求，兩者都會收到你的 IP 位址。
  • 本網站不設定 Cookie，也不做流量統計。它只會在你的瀏覽器中保存你選擇的語言，以及你登入後的工作階段：僅限目前的分頁，或在你勾選「在此裝置上保持登入」時保存在此裝置上。使用 Google 登入時，還會在目前的分頁中保存一次性代碼，直到使用為止。這些都是網站運作所必需的，而只有官方伺服器會收到工作階段與這些代碼。
  • 預告片是一段 YouTube 影片。在你按下「同意並播放」之前，不會從 YouTube 載入任何內容；按下後，YouTube（Google）會收到你的 IP 位址，並可能在你的裝置上儲存 Cookie 或其他追蹤器。你的選擇不會被記住：下次造訪時會再次詢問。 Google 隱私權政策
  • 在你按下「帳號」頁面上的「使用 Google 帳戶登入」之前，不會從 Google 載入任何內容。按下後，你的瀏覽器會前往 Google 的登入頁面（accounts.google.com），接著 Google 會帶著一個一次性代碼將瀏覽器導回本網站，本網站再將該代碼交給官方伺服器。Google 會依其自身的政策，收到你的 IP 位址以及你在其頁面上輸入的內容。 Google 隱私權政策

在遊戲中

遊戲會在你的電腦上保存其設定、你的本機戰績與你的登入狀態。登入狀態保存在系統的安全儲存區中：Windows 上為 DPAPI，macOS 上為鑰匙圈，Linux 上為 Secret Service 金鑰圈；若皆無法使用，則保存在一個只有你的系統使用者才能讀取的檔案中。

遊戲不會自行傳送任何資料：沒有遙測，也不檢查更新。只有在你開啟「線上對局」頁面時，它才會連線到官方伺服器；只有在你下載教練語音時，才會連線到 Hugging Face；進行直連對局時，則會連線到對手的電腦，對手因此會得知你的 IP 位址（遊戲也可能透過 UPnP 在你的路由器上開啟連接埠）。

你在官方伺服器上的帳號

在遊戲中或本網站上建立帳號，以及進行線上對局時，以下資料會傳送到由 OVH 在法國代管的官方伺服器：

  • 帳號：使用者名稱、電子郵件地址、密碼（僅以 Argon2id 雜湊值儲存）、雙重驗證金鑰（已加密）與復原碼（已雜湊）、註冊日期與上次登入日期。
  • 使用 Google 登入：Google 會傳送你的 Google 帳號識別碼、電子郵件地址與姓名。伺服器會保存識別碼與電子郵件地址，姓名僅用於建議使用者名稱。
  • 已登入的裝置：每次登入對應的裝置名稱（遊戲版本與系統，例如「Scacelith/1.0.0 win64」；在本網站上則為瀏覽器與系統）、IP 位址與使用日期。
  • 對局與等級分：每一局線上對局（棋手、著法、每步用時、結果、日期）以及你的等級分。對局期間，你的頭部與手部動作會即時轉送給對手，且絕不儲存。
  • 安全記錄：登入、失敗的嘗試與帳號變更，以及相應的 IP 位址。
  • 公平對弈：你提出的或針對你的檢舉及其備註；放棄與錯過的對局；處分；以及對對局所做的檢查，從偽造或不可能的著法到 Stockfish 引擎的統計數據。

處理目的與法律依據

  • 運作你的帳號與線上對局（登入、配對、等級分、對局紀錄、服務寄出的電子郵件）：這是你註冊使用的服務（《一般資料保護規則》(GDPR) 第 6 條第 1 項 (b) 款）。
  • 保護帳號與伺服器，並確保對局公平（安全記錄、IP 位址、公平對弈檢查、處分）：發布者與棋手的正當利益（GDPR 第 6 條第 1 項 (f) 款）。
  • 從 YouTube 播放預告片：你透過按鈕表示的同意（GDPR 第 6 條第 1 項 (a) 款）。

所有人都能看到的內容

你的使用者名稱、註冊日期、等級分，以及包含每一步著法的完整對局列表都是公開的，可在本網站上、透過伺服器的 API，以及在每局對局的 PGN 中查看。你的電子郵件地址、裝置、登入記錄、處分與公平對弈檢查記錄絕不會顯示。你可以拒絕指名挑戰，但對局無法隱藏。

自動化決策

某些違反遊戲通訊協定的行為，例如偽造的訊息，或在當前局面下不可能走出的著法，是確鑿的作弊證據：此時伺服器會判相關帳號本局落敗，將其停權 24 小時並從排行榜中移除，同時把其對手在過去 60 天內輸給它的等級分退還給對手。24 小時內放棄、中止或錯過三局對局，會暫停計分配對 15 分鐘，之後暫停的時間會更長。僅憑引擎統計數據絕不會導致處分：須由人來決定。你可以透過聯絡信箱，要求重新審查任何決定。

誰會收到你的資料

  • OVH SAS 在法國代管伺服器及其資料。
  • Scaleway SAS（8 rue de la Ville-l'Évêque, 75008 Paris, France）負責寄送伺服器的電子郵件：它會收到你的電子郵件地址、使用者名稱與郵件內容。
  • 當你選擇使用 Google 登入時，Google 會收到你的瀏覽器傳送給它的內容，並適用 Google 自己的隱私權政策。
  • 伺服器的管理員與審核人員會查看帳號資料與公平對弈資料，以營運本服務。
  • 其他棋手可以看到公開的內容；對局期間，你的對手會看到你的著法與動作。
  • 除此之外沒有其他人：任何資料都不會被出售、出租或用於廣告。

帳號資料留存於法國。GitHub、Google 與 Porkbun（負責轉寄寄到聯絡信箱的郵件）位於美國：它們收到的資料，適用其自身的政策，以及它們為將資料傳輸至歐盟以外所採取的保障措施。

保存期限

  • 帳號：保存至你將其刪除為止。電子郵件地址始終未經確認的註冊，會在 24 小時後刪除。
  • 已登入的裝置：保存至你登出為止；閒置 30 天後刪除；最長保存 90 天。
  • IP 位址：30 天後刪除。伺服器日誌只保留截短的位址。
  • 安全記錄：90 天。
  • 放棄與錯過的對局：30 天。
  • 對局與等級分：伺服器保留對局紀錄多久，就保存多久；這些紀錄同時也是你對手的紀錄。你的帳號刪除後，其中你的名稱會改為「deleted#」加上一個編號。
  • 處分、檢舉與公平對弈檢查結果：予以保留，以免遭停權的棋手輕易捲土重來，並讓其他棋手持續受到保護。你的帳號刪除後，這些資料只會與該帳號的編號相關聯。
  • 備份：已刪除的資料可能會在伺服器的備份副本中短暫留存，直到該副本被取代。
  • 寄到聯絡信箱的郵件：保存至回覆所需的期間為止。
