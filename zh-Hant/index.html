I體驗

不是螢幕上的棋盤。
而是棋桌前的一席之地。

Scacelith 找回了真實對局的一切：大廳、寂靜、棋鐘、注視著你的對手，還有棋賽的種種儀式。

♔

第一人稱視角

你透過機器人的雙眼看見一切。環顧大廳、俯身靠近棋盤、抬頭望向對手，或瞄一眼身旁的對局記錄表。

♖

比賽規則

摸了哪顆棋子，就得走哪顆。你要親手按下棋鐘，才算走完一步。走出違例著法，裁判就會前來；第二次違例便判負。

♗

親筆書寫

雙方都在自己的對局記錄表上記下每一步棋，各有各的筆跡，每四十回合翻一頁。你聽得見筆尖在紙上沙沙作響。

♕

旗鼓相當的對手

Stockfish 19 配合你的程度出招，從新手（800）到棋力全開（3500）；每局結束後，都會依 FIDE 規則計算你的等級分。

♘

為這款遊戲而生

從零打造的引擎：基於物理的光照、大理石、上蠟的木材、瓷器與黃銅，穿窗而入的陽光，柔和的陰影與倒影。

♙

十種語言

英文、法文、德文、西班牙文、烏克蘭文、俄文、阿拉伯文、日文，以及簡體與繁體中文。阿拉伯文採由右至左排版。

II遊戲模式

每一局，
都有屬於它的棋桌。

一切都在同一座大廳裡展開，從標題畫面即可進入。離線時，Stockfish 隨時準備好陪你下一盤。

  1. 新對局

    依你選定的棋力挑戰 Stockfish，時限從子彈棋到慢棋任你挑選；也能在同一台電腦上與朋友對弈，各自從自己機器人的視角觀看棋局。

  2. 教練

    一位老師坐在你對面，配合你的程度與你對弈，並為你講解整盤棋：威脅、好棋與失誤。從西洋棋規則一路到專家程度，搭配合成語音（英語發音，附中文字幕）。

  3. 線上對局

    透過 Scacelith 伺服器與真人對手對弈：計分對局、自動配對、挑戰與私人對局。對手的機器人會即時重現對方的一舉一動。

  4. 觀看對局

    兩個 Stockfish 彼此對戰，你則隱身在大廳裡自由穿梭，從一個視角移到另一個視角。

  5. 已儲存的對局

    你的對局會儲存為 PGN 檔案。你可以在大廳中重播，重現真實的思考時間與棋鐘，也可以匯入其他程式的對局。

V線上

真實的對手，
同一座大廳。

在遊戲中登入官方伺服器，與來自世界各地的棋手對弈，依然是第一人稱視角。

  • 每個官方時限都有計分對局，各自擁有依 FIDE 規則計算的等級分。
  • 自動配對、指名挑戰、憑代碼加入的私人對局，以及兩台電腦之間的直連對局。
  • 公平對弈：自動檢查、以引擎分析已結束的對局，以及棋手檢舉。
  • 在本網站查看你的對局紀錄：每一局都能以 PGN 或 GIF 動畫下載。
  • 任何人都能架設社群伺服器：伺服器及其 API 都是自由軟體。

VII製作群

製作群與致謝

西洋棋引擎
Stockfish 19，由 Stockfish 開發者製作（GNU GPL v3）。其神經網路使用 Leela Chess Zero 專案依開放資料庫授權條款（ODbL）提供的資料訓練。
教練語音
教練模式的合成語音由 Supertonic 3 生成。Supertonic 3 是 Supertone 公司的模型，依 OpenRAIL-M 授權條款使用。
字型
EB Garamond 由 Georg Duffner 設計，Cinzel 由 Natanael Gama 設計，Amiri 由 Khaled Hosny 設計（皆採 SIL Open Font License）；棋子符號來自 GNU FreeFont。
開局
開局名稱取自 lichess.org 的 chess-openings 資料庫，已貢獻至公有領域（CC0）。
