# Coach openings: Romanian texts (keys of en.txt). tools/gen_opening_lang.py merges them with the names of
# families.json into assets/coach/openings/ro.lang.
# The coach says "tu" (the game menus stay formal) and is male; nothing agrees with the player's gender (active
# perfect "ai ales", "ai răspuns", present tense, nouns). ș ț with the comma below; quotation marks „…”.
# Names in sentence case ("Apărarea siciliană", "Gambitul damei", "Varianta Najdorf"); their "def" form is the
# definite form with a lower-case head noun ("apărarea siciliană", "gambitul damei", "varianta Najdorf").
# Elliptical names keep a capital, in the names and in the comments ("Siciliana", "Spaniola", "Italiana",
# "Catalana", "Siciliana deschisă", "Dragonul accelerat"). The templates put a name only after a verb, after
# "este", or after "cu", "în", "la": there a name keeps its definite article, since every name is modified (an
# adjective, a genitive or a proper name follows the head noun). Never after "de" or "pe" (the article would drop).
# declined / accepted: {white} there is always a gambit (gambitul damei / regelui, neuter): "l-am refuzat".
# White and Black as players: "Albul", "Negrul" ("pe Alb", "Albului"); "cu culorile inversate" = with the
# colours reversed; "diagonala mare" = the long diagonal; "inversiune de mutări" = transposition.
# Squares as "e4", never inflected ("câmpul e4", "pe e4", never "lui e4"); files as "coloana c", pawns as
# "pionul d"; pieces in words, never piece letters. The voice spells a file letter after coloana / coloane /
# pion / pionul / pionii... (file_pattern of the names fragment); "a" and "e" sound the same as the words, so a
# stray match is harmless. Never write two file letters joined by "și" ("coloanele a și b"): write "coloana a și
# coloana b". An isolated d-pawn is named by its square ("un pion izolat pe d4"): "pion d" is heard as "pion de".
# Centuries in words ("secolul al nouăsprezecelea"), never in Roman numerals.
