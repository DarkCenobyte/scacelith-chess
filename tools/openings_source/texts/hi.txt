# Register: the coach says "तुम" and is male (glossary/hi.md). The player's gender is unknown and a Hindi verb agrees
# with its subject, so the player's actions are transitive perfectives with "ने" ("तुमने ... से शुरुआत की"), never
# "तुम ... खेले"; "we" is हम with the masculine plural, as the glossary allows.
# Opening names are transliterated as Indian players say them (सिसिलियन डिफ़ेंस, रुई लोपेज़, क्वींस गैम्बिट) and do not
# inflect, so "def" is the bare name; the templates put it before a postposition (से, में, को) or before "है". No
# verb agrees with a name (the names differ in gender: ओपनिंग f, गैम्बिट m), hence "को चुना", "से जवाब दिया"; only the
# declined/accepted sentences say "{white:def} खेला", because they only name a gambit (m).
# White and Black are "सफ़ेद" and "काला" (oblique "काले"), masculine. Squares as "e4", files as "c-फ़ाइल", pawns as
# "d-प्यादा" (the names fragment's file_pattern spells the letter for the voice); pieces in words. No digits in the
# comments: "on move two" = "दूसरी चाल में". {n} is a move number: "चाल {n}", as count.moveno writes it.
