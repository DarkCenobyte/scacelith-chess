# Coach openings: Slovenian texts (keys of en.txt). tools/gen_opening_lang.py merges them with the names of
# families.json into assets/coach/openings/sl.lang.
# Standard Slovenian, the coach's register: informal "ti" (the game menus say "vi"). The coach is male; the
# player's gender is unknown, and every Slovenian past tense, future and conditional shows it: for the player
# only the present ("ti pa ga odkloniš", "pazi na ..."), never "si odklonil/a". "beli" / "črni" = White / Black
# as players: masculine (grammar, not anybody's gender), lower case mid-sentence as in Slovenian chess books.
# Names appear only in the nominative ("def" = the citation form with a lower-case first letter, except proper
# adjectives and names: "Najdorfova varianta", "Caro-Kannova obramba"): after "je", after a colon, or as the
# subject. In "declined" / "accepted" White's opening is always a gambit (damin / kraljev gambit, masculine
# inanimate, accusative = nominative after "igraš"), and "ga" refers back to it.
# Composed lichess names (opening.compose.*): Slovenian names a variation after a person with a possessive
# adjective whose ending agrees with the noun ("Steinitzeva varianta", "Steinitzev napad", "Steinitzevo
# nadaljevanje"), so an eponym's "gen" in the names fragment holds that possessive stem (-ov / -ev after c, č, š,
# ž, j / -jev after r and vowels: "Steinitzev", "Winawerjev", "Rétijev"), and only eponyms compose
# (compose_proper_names = false).
# Squares as "e4"; files as "linija c" and pawns as "kmet d" (the file_pattern of the fragment spells those
# letters out, also the second letter of "liniji c in d"); pieces in words, no piece letters. The conjunction
# "a" and the preposition "h" are never used (they would look like file letters). Before a square, s / z follows
# the letter's spoken name: "s c5", "s h6", but "z e5", "z b6"; mostly "s potezo c5" instead.

# ---- Sentences. "pw" = the player (the listener) has White, "pb" = the player has Black; the coach is the
# other side. {white}, {black}, {both}, {variation}, {opening}: opening names; {line}: a composed lichess
# variation name (citation form); {n}: a move number ("pri potezi številka {n}": a cardinal number, no ordinal).
