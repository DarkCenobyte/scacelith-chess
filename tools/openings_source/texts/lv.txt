# Coach openings: Latvian texts (keys of en.txt). tools/gen_opening_lang.py merges them with the names of
# families.json into assets/coach/openings/lv.lang.
# Informal "tu" (the coach's register; the game menus say "jūs"). The coach is male; the player's gender is
# unknown: finite verbs only ("tu sāki", "tu izvēlējies", "tu atbildēji"), never a participle about the player.
# Name forms (families.json, names.lv): "def" is the nominative in running text (lower case except proper
# names: "sicīliešu aizsardzība", "Najdorfa variants"); every family and variation also has the form "acc"
# (accusative: "sicīliešu aizsardzību"), used after "ar" and as a direct object. "White" / "Black" are
# "baltie" / "melnie" (plural, lower case). {n} is a bare number: "gājienā numur {n}" (no ordinal period,
# which the voice would not decline).
# Squares as "e4", files as "c vertikāle", pawns as "d bandinieks" (letter before the noun, no hyphen); pieces
# in words, never piece letters. Light-/dark-squared bishop: "baltlauču / melnlauču laidnis".

# other side.
