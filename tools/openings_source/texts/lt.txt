# Coach openings: Lithuanian texts (keys of en.txt). tools/gen_opening_lang.py merges them with the names of
# families.json into assets/coach/openings/lt.lang.
# The coach says "tu" to the player and is male; Lithuanian simple tenses have no gender, so "tu priėmei" is
# fine for any player. Opening names inflect, so the templates only use them in the nominative ("def" = the
# citation name with a lower-case first word unless it is a proper noun): after a dash ("Tavo debiutas –
# ispanų partija") or after "Tai". The declined/accepted lines refer back to the gambit with "jo"/"jį":
# White's opening there is always a "gambitas" (masculine).
# Names follow Lithuanian chess usage: ethnonym genitives ("prancūzų gynyba", "ispanų partija"), "valdovė"
# for the queen, eponyms spelled the Lithuanian way with a genitive ending ("Aliochino gynyba"), which the
# voice also reads correctly. Squares as "e4", files as "c vertikalė", pawns as "d pėstininkas" (letter before
# the noun; families.json lang_options.lt file_pattern spells the letter for the voice); pieces in words.
