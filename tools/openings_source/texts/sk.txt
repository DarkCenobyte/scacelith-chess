# Coach openings: Slovak texts (keys of en.txt). tools/gen_opening_lang.py merges them with the names of
# families.json into assets/coach/openings/sk.lang.
# The coach's register: informal "ty". The coach is male ("odmietol som ho"); the player's gender is unknown: no
# second-person past tense or conditional, the present instead ("ty ho prijímaš"). "biely" / "čierny" = White /
# Black as players (masculine, lower case mid-sentence).
# Names appear only in the nominative: after "je" (copula) or after a colon, never as an object, so they need no
# case form. The "def" form of a name is its citation form with a lower-case first letter ("sicílska obrana",
# "výmenný variant"), except possessive adjectives and names ("Najdorfov variant", "Caro-Kannova obrana",
# "Rétiho otvorenie", "útok Stonewall"). In "declined" / "accepted" the name is always a gambit (masculine
# inanimate), and "ho" refers back to it.
# Composed lichess names (opening.compose.*): Slovak names a line after a person with a possessive adjective that
# agrees with the noun ("Steinitzov variant", "Steinitzova obrana", "Alapinovo otvorenie"), or, for a name ending
# in a vowel, with its invariable genitive ("Morphyho obrana", "Kieseritzkého gambit"). So in the names fragment
# the eponyms' "gen" holds the masculine form (for variant, útok, gambit, systém, protigambit, protiútok; "Line"
# is said "variant" too) and "nom" the feminine form (for obrana, pasca); the neuter "otvorenie" adds "o" to
# "gen" ("Alapinovo"; lichess only joins consonant-final names to "Opening"). Only eponyms compose
# (compose_proper_names = false).
# Squares as "e4"; files as "stĺpec c" and pawns as "pešiak d" (the file_pattern of the fragment spells those
# letters out); pieces in words. The a-file only as "stĺpec a aj stĺpec b" (a lone "a" is also the word "and").
